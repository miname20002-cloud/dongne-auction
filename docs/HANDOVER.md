## 현재 경매 규칙
- LOT 내부 명칭은 유지하지만 사용자 화면에서는 **"경매"** 로 표시
- 상품당 60초
- 마지막 15초 이하에서 입찰 발생 시 마감시각을 **입찰시각 +30초**로 연장
- 반복 연장 가능
- 상품 사이 10초
- 5개 상품 자동 진행
- `auto_run=TRUE` 상태에서 자동 진행
- Apps Script 함수 수동 실행 불필요

## 랜딩 최종 구조
- 어제 마지막 확정 레이아웃 계승: 첫 상품 대형 카드 + 나머지 상품 2열 배치
- "나의 낙찰가는?"
- 1,000원 START
- 회원가입 없이 바로 참여
- 서버 상태에 따라 LIVE/준비 중 표시
- 상품 5개 전체 표시
- 상품당 60초
- 마지막 15초 이하 입찰 시 +30초, 반복 연장 가능
- 상품 사이 10초
- 입찰 1회 이상이면 커피 기프티콘 10명 자동 추첨
- 경품 안내 → `result.html`
- 종료된 경매 표시
- sticky 입찰 CTA → `live.html`
- 사용자 화면에서 LOT/cycle/round, 9시 고정, 예측왕 3만원, `predict.html` 사용하지 않음

## 경품
- 입찰 `accepted` 1회 이상이면 자동 추첨 참여
- 1인 1추첨권
- 커피 기프티콘 10명
- 별도 응모 행동 없음
- `result.html`에서 규정/당첨자 발표 안내
- 발표 전 Google Form 신청 비활성
- 안내문: **"당첨자 발표 후 신청이 열립니다"**
- 발표 후 당첨자만 수령 확인 코드 + 닉네임 + 휴대폰 번호로 신청
- Google Form의 예측왕 3만원 선택지는 제거됨
- 비로그인 제출 가능 확인됨

## 테스트 종료 후에만 할 일
1. 전체 광고 테스트 기간 `accepted` 입찰 `session_id` 수집
2. `session_id` 중복 제거
3. 무작위 10명 추첨
4. `result.html`에 당첨자 발표
5. Google Form 신청 활성화
6. 당첨자 `session_id`/닉네임 대조
7. 기프티콘 발송
8. 지급 완료 후 휴대폰 번호 삭제
